A self-hosted backup server

I didn't want my photos living only in someone else's cloud, so I turned an old 2016 Alienware desktop into a headless Linux server that backs up my phone automatically. It's reachable from anywhere through a private VPN, and nothing is exposed to the open internet.

The stack

The server runs headless, with no monitor or keyboard; I manage it entirely over SSH. Immich, an open-source photo platform, runs as four containers defined in one Docker Compose file, so the whole thing is easy to rebuild or move to new hardware.

My phone talks to the server over Tailscale, a WireGuard-based VPN. Instead of forwarding ports on my home router, only devices signed in to my private network can reach it.

How I built it

Five steps, from BIOS settings to a locked-down remote connection.

  1. Prepped the hardware

    Set Secure Boot and switched storage to SATA AHCI in the BIOS for a clean Linux install, then built UEFI install media.

  2. Installed Ubuntu Server, headless

    Installed Ubuntu Server 26.04 LTS without a desktop environment and moved all administration to SSH.

  3. Networked it over Wi-Fi

    Configured wireless networking with netplan so the box can live wherever it fits, not next to the router.

  4. Deployed Immich with Docker Compose

    Brought up the application, machine-learning, PostgreSQL, and Valkey containers, then pointed the iOS app at the server and backed up 9,000+ photos.

  5. Locked down remote access

    Set up Tailscale so I can reach the server from anywhere without opening a single port on my home network.

The security catch

While reviewing the network setup, I found that one of the server's interfaces was reachable on a public address from my ISP. I identified it and shut it off, so access only goes through the VPN. It was a good reminder to check what's actually exposed instead of assuming.

What I practiced

  • Linux server administration from the command line
  • Container orchestration with Docker Compose
  • VPN-based remote access with zero open ports
  • Auditing my own network for exposure

What's next
