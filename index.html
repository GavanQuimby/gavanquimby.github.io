The home lab

A 2016 Alienware, reborn as a headless photo server

I didn't want my photos living only in someone else's cloud. So I wiped an old gaming desktop, installed Ubuntu Server 26.04 with no desktop at all, and run Immich in Docker. My iPhone backs up to it automatically: 9,000+ photos so far.

It's reachable from anywhere over a Tailscale VPN, with no ports open on my home router.

The catch I'm proudest ofWhile auditing the setup, I found one of the server's interfaces sitting on a public ISP address. I shut it off, and now the only way in is through the VPN.
